## How Pocket Lab protects control

<div class="pl-threat-story-grid"><article><span>1</span><h3>Browser asks</h3><p>The PWA requests operations. It does not talk directly to NATS, execute shell commands or own backend secrets.</p></article><article><span>2</span><h3>FastAPI decides</h3><p>Caddy keeps the browser same-origin and FastAPI remains the control authority for /api/lite/* operations.</p></article><article><span>3</span><h3>Messaging delivers</h3><p>NATS/JetStream carries modeled command and event flows; it is not a browser API.</p></article><article><span>4</span><h3>Agents execute</h3><p>Workers, node agents and the separate supervisor own execution, reconnect and recovery semantics.</p></article><article><span>5</span><h3>Evidence returns</h3><p>Sanitized events, health and promoted evidence project back through FastAPI and static documentation.</p></article></div>
