## Execution rules

Phone-owned scenarios preserve the FastAPI → NATS/JetStream → worker/agent control plane. DEV-PC scenarios use only registered fixed runtime lanes.

`PASS`, `FAIL`, `PARTIAL`, `BLOCKED`, `NOT_ASSESSED` and `NOT_APPLICABLE` remain distinct. Missing prerequisites must never be silently reported as PASS.

The canonical dependency-confusion scenario is `dependency-confusion-and-lock-integrity`.
